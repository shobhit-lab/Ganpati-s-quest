# 🪔 Ganpati's Journey

> **A 3-stage interactive game celebrating Ganesh Chaturthi — from welcoming Bappa to the final Visarjan.**

🎮 **Play the game:** [ganpatis-journey-five.vercel.app](https://ganpatis-journey-five.vercel.app/)

---

## 🌺 About the Game

**Ganpati's Journey** is a festive, story-driven **3-stage browser game** created for a **Ganesh Chaturthi Game Design Hackathon**.

The game takes players through a complete celebration journey:

**🍬 Welcome Bappa → 🏛️ Build the Pandal → 🌊 Complete the Visarjan**

Each stage introduces a unique gameplay mechanic while continuing the same story.

---

## 🎮 The Three Stages

### 🪔 Stage 1 — Modak Catch

Help welcome Bappa by catching falling sacred offerings.

| Item | Points / Effect |
|---|---:|
| 🍡 Modak | **+10 points** |
| ✨ Mega Modak | **+50 points** |
| 🌸 Flowers | **+25 points** |
| 🏺 Amrit Kalash | **+1 life** |
| ❌ Missed Modak | **-1 life** |

**Goal:** Reach **1,000 points** to advance.

**Controls**
- **Desktop:** Arrow Keys
- **Mobile:** Touch / Drag

---

### 🏛️ Stage 2 — Pandal Builder

Prepare Bappa's grand pandal before the countdown ends.

- Drag decorations into glowing slots
- Build consecutive placement streaks
- Watch the pandal illuminate as you decorate
- Answer **Bappa Bonus Quizzes**
- Correct answers can grant **+5 seconds**

**Goal:** Complete the pandal before the timer runs out.

---

### 🌊 Stage 3 — Path of Light

The final challenge.

Rotate the sacred stepping stones to create an **unbroken glowing pathway across the river** and guide the journey toward Visarjan.

**Goal:** Solve the puzzle and complete the final journey.
